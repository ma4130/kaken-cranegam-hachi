# はっちーのクレーンパーク

はっちーをテーマにした3Dクレーンゲーム。元の `ma4130/kaken-cranegame` を基に、赤・クリーム・黄色の筐体と4学科・コースのコレクションを追加。

## 遊び方

1. 「パークへ入る」→「あそぶ」。
2. ① → を長押しし、よい位置で離す。
3. ② ↑ を長押しして離すと、自動で景品をつかむ。

タッチ・マウス・キーボード（→、↑）対応。音は初期OFF。コレクションはこの画面を開いている間だけ保持します。

## 画像について（保存先は相談待ち）

ユーザー提供画像はGitHubに一切含めていません。初期表示はコードで描いた学科バッジです。

画面の「はっちー画像を選ぶ」から、元の4枚を端末内で選べます。ファイル名の `電気科` / `機械科` / `環境化学` / `電力管理` を使って対応付けます。選んだ画像はブラウザ内のObject URLで表示するだけで、サーバー送信や永続保存は行いません。再読み込み時には選び直してください。画像をCSS/JSに埋め込むこともしていません。

追加ポーズの生成・画像の公開先・容量上限は未決定です。元の4枚の合計は約69KiBです。

## スマホ操作・データベース

はっちー版専用のFirebaseプロジェクト `kaken-cranegam-hachi` を使用します。元の `kaken-cranegame` の設定やデータは使用しません。

1. スクリーンで「スマホ参加用の部屋を開く」を押します。
2. スマホでQRコードを読み取り、ニックネーム（8文字まで）を入力します。
3. 順番が来たら1人2回。操作方法を「ボタン／スティック」から選べます。
4. ①右へ動かして離す → ②奥へ動かして離す → 自動キャッチ。

スティックは右／上へ倒している間動き、指を離すとその軸の位置を確定します。2軸を同時に自由移動する操作ではありません。操作中は方式の切り替えをロックします。タッチ、マウス、キーボードに対応しています。

- Firebase Authentication：匿名認証。メール・パスワードの入力は不要。
- Firestore Standard：東京 `asia-northeast1`、Spark（無料）プラン。
- `hachi_rooms/{room}`：部屋・順番待ち・結果。
- `hachi_rooms/{room}/players/{uid}`：本人の参加情報と押下／解放イベント。
- ホストだけが部屋の進行を書き換えられ、参加者は自分の情報だけを書き込めます。
- 各プレイの識別子を付け、前のプレイの遅延入力を受け付けません。
- 部屋は23時間で書き込み期限が切れます。画面の再読み込み後は、新しい部屋を開いてください。古い部屋は自動削除しません。
- 通信は操作・フェーズ変化・約1分間隔の確認時に送ります。毎フレームは送りません。
- スマホの獲得履歴はそのブラウザ内に保存します。画像は従来どおり端末内だけで読み込みます。

`firestore.rules` が公開済みのルールです。Webアプリ設定のAPIキーは公開可能な識別用設定です。管理者の秘密鍵は含めていません。

## 検証

- `node --check js/screen.js` / `js/controller.js` / `js/controls.js` / `js/net.js`。
- `node tests/firestore-live.mjs`：専用プロジェクトで匿名ユーザー・一時部屋を作り、所有権・入力制限など11項目を確認してテストデータを削除します。元ゲームには接続しません。
- ChromeでQR参加、スティック移動、ボタンへの切り替え、獲得結果、順番待ち、キャンセルと再参加を確認。

## 開発・公開

ビルド不要。`python -m http.server 8876` で起動してブラウザで開きます。Three.jsおよびGoogle FontsはCDNから読み込みます（インターネット接続が必要）。

公開先：https://ma4130.github.io/kaken-cranegam-hachi/ （GitHub Pages、main / root）。

`?test` を付けると元ゲーム同様に `window.__crane` のテスト操作が使えます。
